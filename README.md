# ForgeWell Gym

A dark, premium single-page marketing website for ForgeWell gym in Bhopal.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The page is built with React, Vite, Tailwind CSS, and handcrafted SVG icons. Content is defined in `src/data/forgewellData.json`; images are served from `public/`.
